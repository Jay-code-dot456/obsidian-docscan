# 文档扫描 DocScan

移动端优先的 Obsidian 文档扫描插件：拍照 → 手动框选四角 → 透视矫正拉平 → 存入库并插入链接。纯 JS 实现，**零依赖、零构建**。

## 安装

把整个文件夹拷到库的 `.obsidian/plugins/docscan/` 下（至少包含 `main.js`、`manifest.json`、`styles.css`），在「设置 → 第三方插件」里启用即可。移动端把这三个文件放到同样路径即可。

## 使用

1. 点左侧栏的扫描图标，或命令面板搜「扫描：拍照并矫正」。
2. 默认弹出系统选择器，可选「拍照」或「相册」（在设置里可改为「直接相机」一键唤起摄像头）。
3. 拖动四个角对齐文档/PPT/屏幕的边缘，点「矫正」。
4. 预览无误后点「保存」——图片存入设置里的目录，并在当前笔记光标处插入 `![[...]]`。

## 设置

- **存放目录**：扫描件保存路径，默认 `attachments/scans`。
- **输出长边**：矫正后长边像素上限，默认 1600。
- **JPEG 质量**：默认 0.92。
- **对比度增强**：默认 1.0（关闭）。PPT / 彩色图表保持 1.0；纯文字纸质可调 1.2~1.5。

## 已知边界 / 后续

- v0.1 **不做自动边缘检测**，四角靠手动。原因是移动端优先，避免引入 opencv.js（约 8~10MB WASM）。
- 自动检测计划 v2 再接（opencv.js / jscanify，桌面优先、懒加载）。
- OCR / 可检索标签属于更后期规划，可在 frontmatter 预留 `tags` / `ocr` 字段承接。
